# 云服务器带宽怎么选：先算清并发和月流量，再决定买固定带宽还是按流量计费

买云服务器的时候，CPU 和内存买错了，最多是跑得慢一点；带宽买错了，是两头吃亏——买大了每个月白交钱，买小了页面一有人访问就打转。更麻烦的是，带宽是少数几个"看起来很简单，实际有好几层坑"的参数：同样写着 100M，可能是独享端口，也可能是共享；同样写着不限流量，上行带宽可能只有 20M。

这篇文章不绕圈子，先把带宽和流量的基本关系讲清楚，再给出一套能自己算的估算方法，最后拿雨云的两种网络计费模式作为具体样本，看看什么业务该选高带宽按流量、什么业务该选低带宽不限流量。

## 先把带宽和流量分开看

带宽（Mbps）是水管的粗细，代表任意一个瞬间最多能灌多少水。流量（GB）是这个月总共放掉了多少水。这两件事完全独立：一条 5Mbps 的管子如果一直满速跑，一个月能跑出十几 TB；而一条 1Gbps 的管子如果只偶尔跑几秒，月流量可能连 100GB 都不到。

换算关系只需要记一个：1 Byte = 8 bit。所以 1Mbps 的实际下载速度上限大约是 128KB/s，5Mbps 大约 640KB/s，100Mbps 大约 12.5MB/s。很多人买完 1M 带宽的机器，发现下载速度只有 100 多 KB，不是商家缩水，是单位没换算过来。

还有一个细节值得单独说：雨云套餐页上的"上传"和"下载"是分开标的，而且方向容易理解反。页面写着"上行 25Mbps、下行 50Mbps"的机型，用户从服务器拉数据的实测速度接近 50Mbps，往服务器传的速度接近 25Mbps。也就是说，"下载"标的是用户取数据的方向（这台机器的出网能力），"上传"标的是用户写数据的方向。两边的数字经常不对称，往下看套餐表你会发现，很多方案下行给得很慷慨，上行只有它的零头——这个差别对建站没影响，对往外推数据的业务就是直接的天花板。

## 三步算出自己大概需要多少带宽

不用做压力测试，三个数字就能估个大概。

**第一步，量一下单次访问的体积。** 打开你的网页，看总下载量是多少 MB。一个纯文字博客页面可能只有 200–400KB，带几张没压缩的原图就轻松上到 2–3MB。差一个数量级，后面的结果就差一个数量级。

**第二步，估一下峰值并发。** 注意是"同一时刻有几个人在访问"，不是日访问量。日 3000 PV 的站点，如果访问全天均匀分布，峰值并发可能只有几个到十几个人。真正会顶穿带宽的是被分享到群里、上了热搜、或者定时任务同时拉取的那几分钟。

**第三步，套公式。**

> 需要的带宽（Mbps）≈ 平均页面大小（MB）× 8 × 并发数 ÷ 你能接受的加载秒数

举个例子：页面 200KB（约 0.2MB），峰值 20 人同时打开，你希望 3 秒内加载完，那就是 0.2 × 8 × 20 ÷ 3 ≈ 10.7Mbps。换个场景：页面 2MB（图片站），峰值 30 人，还是 3 秒，算出来是 160Mbps。同一个公式，结论从"5M 就够"跳到"得上大带宽套餐"，差别全在页面体积上。这也就是为什么压缩图片、把静态资源丢 CDN，比直接加钱买带宽更划算。

月流量则简单得多：平均页面大小 × 月访问量。一个 500KB 的页面被访问 10 万次，大约消耗 50GB 出网流量。这个数字决定了你在"按流量计费"的套餐上会不会超。

## 不同场景大概要几兆，一张表对照

下面的档位是基于常见业务形态整理的参考区间，实际还是以上面那三步算出来的结果为准。

| 使用场景 | 建议带宽 | 月流量参考 | 说明 |
| --- | --- | --- | --- |
| 测试环境、学习用途 | 1–3Mbps | 50GB 以内 | 只跑 SSH、小文件传输 |
| 个人博客、纯静态站 | 3–5Mbps | 100GB 以内 | 页面小、并发低 |
| 企业官网、小型 WordPress | 5–10Mbps | 200GB 左右 | 图片压缩过、接 CDN 更省 |
| 内容站、带数据库的动态站 | 10–30Mbps | 300GB–1TB | 并发开始有意义 |
| API、接口服务 | 看请求体，不看出网 | 视调用量 | 更该关注连接数和延迟 |
| 图片站、软件下载页 | 50–100Mbps 起 | 1TB 以上 | 流量成本成为主要开销 |
| 视频、大文件分发 | 100Mbps–1Gbps | 按流量包算 | 建议配 CDN 回源 |
| 游戏服务端 | 上行看人数 | 视玩法 | 单核性能和延迟比带宽更关键 |

游戏服是个例外，它对带宽数字不敏感，但对延迟和单核性能敏感。雨云官方在游戏云选购页给出的参考是：入门级 2核4G / 10M 上行可承载纯净服 12 人以上、50 个模组的 mod 服 6 人；进阶级 4核8G / 15M 上行对应纯净服 25 人以上；6核12G / 20M 上行对应纯净服 40 人以上。带宽在这里不是瓶颈，CPU 主频和玩家到机房的延迟才是。

## 固定带宽还是按流量计费：雨云把两种模式都摆出来了

雨云在多数区域的云服务器提供两种网络计费模式，官方文档里的定义很直白：

- **流量叠加型（套餐流量计费）**：带宽给得高，按流量使用量计费，上下行流量都计入套餐流量，可以购买流量包补充，没用完的流量能结转到下一个补充周期。补充周期是固定的 31 天，不按自然月算。
- **流量不限型（固定带宽计费）**：带宽相对较低，流量不单独计费，按你选的带宽规格收钱。

选择逻辑其实不复杂：

流量波动大、平时闲但偶尔需要冲高带宽的业务，走流量叠加型。比如文件下载页、活动页、图片站——你需要的是"那一瞬间管子够粗"，而不是管子一直开着。反过来，长期稳定占用、流量持续在跑的业务，走流量不限型更稳。API 服务、数据同步、定时爬取、长连接中转，这类业务如果按流量算，月底账单会很难看。

有两个机制得提前知道。一是**限速**：流量叠加型套餐的流量用完后会进入限速状态，官方文档举例说明限速后带宽会降到 5M 左右，不同区域的限速档位不完全一致，买之前看购买页的说明。补充流量后恢复正常带宽，也支持设置自动充值流量包。二是**流量阈值控制**，可以自己设一个日流量阈值和触发后的限速带宽，防止某天被刷掉一个月的量。

流量包价格按机房差异很大，官方文档列出的档位可以感受一下：浙江温州单线/多线 1024GB 是 100 元，浙江绍兴 BGP 多线 1024GB 是 150 元，湖北十堰电信 1024GB 只要 50 元、2048GB 是 100 元，广东深圳电信 200GB 是 25 元。同样是按流量计费，不同机房的单位成本能差出两三倍。如果你的业务跑的是按量模式，机房选型对成本的影响可能比配置选型还大。

## 比带宽数字更容易踩的四个参数

**一是独享还是共享。** 页面上写着 100M、200M、1Gbps，要先确认是独享端口还是共享。共享带宽在高峰期会被邻居抢走，标称值只在空载时成立。雨云的产品介绍里对游戏云特别提到"宽带隔离技术"，云服务器区域也有 BGP、精品网、单线等线路区分——线路类型比带宽数字更能决定实际体验。

**二是计费方向。** 流量叠加型是上下行公网流量共同计入套餐流量，不是只算下行。服务器往外备份、往对象存储同步数据，这些都会消耗流量额度。

**三是独立 IP 是单独收费的。** 雨云官方文档明确写了最终价格由计算资源费用和独立 IP 费用两部分构成。日常报价里通常已含一个 IPv4，追加一般是 5 元/个/月，部分区域还有原生 IP、住宅 IP 的选项，价格更高。NAT 机型不带独立公网 IP，靠端口映射对外服务，端口数量有上限，便宜但限制也多。

**四是备案。** 内地机房（江苏宿迁、湖北十堰、浙江宁波、广东深圳、重庆等）用来跑带域名的网站需要先备案，香港和洛杉矶节点免备案。同时，国内机房和海外机房的内地访问延迟差距是实打实的，香港通常明显低于洛杉矶，具体值建议自己 ping 一下再决定。

## 落到选择上：几类人该怎么做

**只跑个人博客或静态站。** 香港入门版或标配版就够了，5M 上下行配合图片压缩和 CDN，日常访问不会有感知。没必要一上来买高配，带宽买大了是纯粹的浪费。

**跑 WordPress 或带数据库的动态站。** 从 2核4G 起步，对应香港中配（￥48）或洛杉矶中配（￥44）。1核1G 跑 WordPress 加数据库会很吃力，问题通常先出在内存而不是带宽。

**做下载站、软件分发。** 直接看洛杉矶，并且优先考虑流量叠加型——低配加高带宽的组合比高配加低带宽更符合这类业务。先把流量包单价算进成本，不同机房差价很大。

**跑 API、爬虫、数据同步。** 走流量不限型。这类业务的特点是流量持续稳定、不会突然冲高，按带宽包月比按量付费更可控。

**开游戏服。** 别只盯着带宽，先看 CPU 单核性能和玩家到机房的延迟，再看上行够不够。

最后两个能省钱的信息，都是官方页面上写着的：新用户注册后可以领一张首月 5 折券，年付在购买页会直接显示折扣；产品支持 7 天无理由退订（每个账号限 3 次）。不确定自己需要多少带宽的话，先买一个月的低配跑几天，看看后台的实际流量曲线，再决定要不要升级——雨云支持随时升降配和弹性扩容，这条路径比一次性买对更现实。
